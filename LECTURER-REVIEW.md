# Lecturer review checklist before teaching use

## Scientific details requiring confirmation

- **85% vs 80% HRmax:** The high-intensity practical is headed "85% HRmax", but the original 4–5 minute adjustment instructions instruct changes according to "80% HRmax". The digital workbook calculates and labels an 85% target and explicitly shows the source discrepancy. Confirm which threshold students should use before the session.
- **VAS upper endpoint descriptions:** Only the zero endpoint is given for each of the four scales: hunger = not hungry; satisfaction = completely empty; fullness = not full; prospective food consumption = nothing. The interface leaves the 100 endpoint unlabelled other than "Endpoint not specified in workbook". Approve scientifically appropriate anchors if required before teaching.
- **RPE rating scale:** No particular RPE scale is stated. Staff should specify which scale to use and provide it to students consistently.
- **Intensity-specific starting settings:** The original male/female equipment settings appear as separate table references; they should not be treated as mandatory individual prescriptions. Confirm any changes to these values with the teaching team.
- **Equipment power conversion:** Resistance on the basket (kg) × 60 rpm is the reference supplied for the original cycle equipment. Confirm applicability to the actual laboratory ergometers.

## Practical deployment checks

- Confirm exercise screening, informed consent and institutional supervision are addressed by the established practical procedure; a checkbox is not a replacement.
- Test an example record in the actual browser and devices used in the practical.
- Confirm CSV files open with separate columns in your preferred version of Excel and that any numerical RPE scores share a common interpretation.
- Remind students to use anonymous participant IDs and to export a JSON backup at the end of the session.
- If collecting an entire class dataset, agree a file submission/combination method. This site intentionally does not aggregate data from different students' devices automatically.

## Scientific source

All practical timings, four VAS variables, three appetite measurement points, data collection intervals, original zero anchors, protocol settings and six questions were transcribed/adapted from `PoN (Week 4) Exercise and apetite regulation(1).docx` supplied for the build. The explanations are teaching summaries rather than claims of measured hormonal outcomes.
